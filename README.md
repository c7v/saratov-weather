# Данные погоды — Саратов

Этот репозиторий содержит архивные данные о погоде по городу **Саратов**.

## Структура репозитория

Данные организованы по иерархической структуре: год/месяц/день

### Пример структуры папок

- **Год** — папка с четырёхзначным годом (например, `2023`)
- **Месяц** — номер месяца (`01`–`12`)
- **День** — номер дня месяца (`01`–`31`)

## Назначение

Репозиторий предназначен для:
- хранения и анализа погодных данных
- использования в аналитических и исследовательских проектах
